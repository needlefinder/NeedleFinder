## Summary
Overview of 3D Slicer as a platform for prototyping, developing and evaluating image-analysis tools for clinical research, in the context of the NCI Quantitative Imaging Network (QIN, started 2008). 3D Slicer is a free, open-source medical image computing application that, like a radiology workstation, supports versatile visualisation but also provides automated segmentation and registration; unlike a workstation it is free and hardware-independent. As a programming platform it provides abstractions for data communication, visualisation and user-interface development and is designed to be extended through 3D Slicer extensions and redistributed. The paper presents QIN use cases and future directions for imaging-biomarker development and validation.
